# 圣诞粒子树 · Noël

一个打开就能玩的 3D 粒子圣诞树网页。无需安装依赖，无需注册账号。

## 方法一：在自己的电脑上打开（最简单）

1. 打开仓库：https://github.com/Songxuyang/christmas-particle-tree 。
2. 点击文件列表上方的绿色 **Code** 按钮，选择 **Download ZIP**。
3. 下载完成后，右键压缩包，选择“解压全部”或“解压缩”。不要直接在压缩包里面打开网页。
4. 打开解压出来的文件夹，找到 **index.html**。
5. 双击 **index.html**，它会在默认浏览器中打开。推荐 Chrome、Edge、Safari 或 Firefox。
6. 如果双击后出现代码，右键文件 →“打开方式”→ 选择浏览器。

看到圣诞树就表示成功，不用输入命令。GitHub 文件列表里点击 index.html 显示的是源码，不是运行后的网页。

## 方法二：生成一个手机、朋友都能打开的网址（GitHub Pages）

此方法通常适用于公开仓库；私有仓库是否支持取决于 GitHub 套餐。需要仓库管理员操作一次。

1. 登录 GitHub，打开上面的仓库链接。
2. 点击仓库顶部的 **Settings**（设置）。手机界面可能需要展开顶部菜单。
3. 在左侧 **Code and automation** 分组下点击 **Pages**。
4. 在 **Build and deployment** 下，把 **Source** 选为 **Deploy from a branch**。
5. 在 **Branch** 中选择 **main**，旁边的文件夹选择 **/ (root)**。
6. 点击 **Save**，等待几分钟后刷新 Pages 设置页。
7. 页面出现 **Your site is live at…** 时，点击 **Visit site**，或复制它显示的网址发送给朋友。

按当前仓库名，默认网址通常是：

**https://songxuyang.github.io/christmas-particle-tree/**

这个地址需要先完成上述发布步骤才会生效。请以 Pages 设置页实际显示的地址为准；这份说明不代表已经开启 Pages。

如果出现 404：先确认选择了 main 和 / (root)，再到仓库顶部 **Actions** 查看 Pages 部署是否成功，等待完成后刷新。以后 main 分支更新网页，Pages 通常会自动重新部署；若仍看到旧版，按 Ctrl+F5（Mac：Command+Shift+R）强制刷新。

## 网页里的按钮怎么用？

| 功能 | 用法 |
| --- | --- |
| 旋转圣诞树 | 电脑按住树左右拖动；手机用手指左右滑动 |
| 放大、缩小 | 电脑滚动鼠标滚轮 |
| 三个配色圆点 | 切换香槟金、冰雪银、玫瑰粉 |
| 右侧旋转图标 | 开启或关闭自动旋转 |
| 右侧雪花图标 | 开启或关闭飘雪 |
| 右侧音符图标 | 开启或关闭圣诞铃声；需要先点击才播放 |
| 许个愿 | 播放粒子绽放，显示祝福 |
| 暂停动画 / 继续动画 | 定格或继续动画，音乐单独控制 |
| 重置视角 | 恢复初始角度、缩放大小，收拢许愿粒子 |
| 保存图片 | 下载当前粒子画面为 PNG，不包含界面文字和按钮 |
| 全屏显示 / 退出全屏 | 进入或退出全屏；电脑也可按 Esc 退出 |
| 使用说明 | 在网页中查看操作帮助 |

部分手机浏览器不支持全屏，该按钮会自动禁用。若保存图片没有弹出下载，请查看浏览器下载列表，或使用系统截图。

## 方法三：给开发者的本地服务器（可选）

只有需要本地 HTTP 服务时才用这种方法；普通观看选方法一即可。

安装 Python 3 后，在包含 index.html 的文件夹中打开终端，运行：

```sh
python3 -m http.server 8000
```

Windows 若找不到 python3，可改用：

```powershell
py -m http.server 8000
```

保持终端开启，在同一台电脑的浏览器地址栏输入 `http://localhost:8000`。结束时回到终端按 Ctrl+C。localhost 地址仅供本机使用；给朋友分享请用方法二。

## 技术说明

原生 Canvas 绘制 3D 投影粒子，无需构建。音乐由浏览器合成；Google Fonts 无法加载时自动使用系统字体，不影响粒子与交互。支持手机布局，默认尊重系统“减少动态效果”的偏好。
