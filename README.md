# Noël · 3D 粒子圣诞树

使用原生 Canvas 绘制三维粒子圣诞树，无需安装依赖或构建。

## 运行

直接在浏览器打开 `index.html`，或在仓库目录启动静态服务：

```sh
python3 -m http.server 8000
```

在浏览器访问服务的 8000 端口。

## 交互

- 拖动旋转，滚轮缩放；支持触屏拖动。
- 切换香槟金、冰雪银和玫瑰粉配色。
- 开关自动旋转、飘雪和合成圣诞铃声。
- 点击 Make a wish 触发粒子绽放与祝福。
- 自动适配手机，并尊重系统减少动态效果的偏好。

字体使用 Google Fonts；离线时自动使用系统字体，粒子与音乐不依赖外部资源。
